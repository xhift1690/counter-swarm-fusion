Read this before trusting the numbers

The clean separation between drones and decoys is partly real (two independent classifying sensors) and partly an artifact of a deliberately simple classification model that becomes overconfident quickly. The synthetic sensors are also simpler than real ones. Treat this as an architecture demonstration, not a performance claim.

How these are measured

Each condition runs the same seeded random scenarios. At every step, confirmed tracks are matched to ground-truth targets with the Hungarian algorithm (50 m gate). Recall is the share of target-steps with a matched track. An ID switch is a target changing track ID; a fragmentation is a tracked target losing its track. Threat AUC pools the final score of each target across runs. Ground truth is used for scoring only, never by the tracker.

How much to trust the threat-score results

The score is calibrated on labelled trials from the same simulator, so these results show the method works, not how it would perform on real sensors. On the baseline the simulated classifier reports higher confidence when it is right, which flatters any score that learns from it. The “uninformative classifier confidence” condition is the fairer test.

Design choices

SAPIENT-aligned data model

Detections, fusion and tracks are kept as three separate concepts, mirroring the SAPIENT interface semantics.

Sensor capability profiles

Each synthetic sensor declares its own detection probability, false alarm rate, range and classification ability.

Track lifecycle as operator trust

Tracks move from tentative to confirmed to dropped, like a decision module managing confidence.

Scope

Fusion software only. No sensor design, jamming or interceptor logic.

Known limitations

Naive classification fusion

A multiplicative Bayesian update that drives scores toward 0 or 1 too fast. Next: calibrated likelihoods or a Beta-Binomial / Dirichlet model.

Constant-velocity motion model

Real drones maneuver. An Interacting Multiple Model filter would handle turns better.

Single-assignment data association

Gated nearest-neighbor with the Hungarian algorithm. Dense swarms would benefit from JPDA or multi-hypothesis tracking.

Track fragmentation

Some duplicate tracks form from false alarms. A duplicate-suppression heuristic helps; per-sensor tuning would be the principled fix.
